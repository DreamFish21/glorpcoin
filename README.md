# GlorpCoin — игра для Twitch-чата

GlorpCoin — симулятор рынка для Twitch-чата. Команда `!glorp` добавляет зрителя в раунд. Начальный баланс задаётся в настройках раунда; начальный курс — 50 ₽ за GC. Команды `!к 100` и `!п 100` покупают и продают GC; обычный курс меняется раз в 8 секунд, после 4–10 обычных изменений происходит отдельный скачок на 100–140 ₽. Это только игровая валюта, реальные деньги и криптовалюта не используются.

## Локальный запуск

1. Запусти Streamer.bot и подключи к нему Twitch.
2. В Streamer.bot открой **Servers / Clients → WebSocket Server**, укажи `127.0.0.1:8080` и запусти сервер.
3. Запусти Node.js 20 или новее, затем в этой папке выполни `node server.js`.
4. Открой `http://localhost:3001`, войди в Twitch как владелец канала и нажми **Подключить Streamer.bot**.
5. Страница игрока доступна на `http://localhost:3001/player.html`.

В кабинете игрока требуется вход через Twitch. Имя участника берётся из подтверждённого Twitch-аккаунта и не вводится вручную.

## Публичный HTTPS-хостинг на Render

Файл `render.yaml` содержит готовую конфигурацию Render. Чтобы опубликовать приложение:

1. Добавь проект в свой GitHub-репозиторий и подключи его в Render как **Web Service** по Blueprint `render.yaml`.
2. После создания сервиса скопируй выданный HTTPS-адрес, например `https://имя-сервиса.onrender.com`.
3. Render автоматически создаст `HOST_PASSWORD` и `SESSION_SECRET`. На главной странице нажми **Войти как стример** и используй `HOST_PASSWORD` из Render → **Environment**. Не отправляй этот пароль зрителям.
4. Открой Streamer.bot в браузере стримера и подключи его WebSocket.
5. Отправь зрителям `https://имя-сервиса.onrender.com/player.html`.

Для страницы игрока обязательно настроить Twitch OAuth: добавь `TWITCH_CLIENT_ID` и `TWITCH_CLIENT_SECRET` в Render Environment и установи `REQUIRE_TWITCH_LOGIN=true`. Игроки входят через Twitch; сервер связывает профиль и сделки только с логином из проверенной сессии.

Для использования игроками необходим Twitch OAuth: добавь в Render → **Environment** `TWITCH_CLIENT_ID` и `TWITCH_CLIENT_SECRET`, а для автоматического распознавания владельца канала — ещё и `BROADCASTER_LOGIN` (Twitch login стримера). OAuth redirect URL должен быть `https://имя-сервиса.onrender.com/auth/twitch/callback`. Секрет храни только в Render, не публикуй его. Вход через Twitch в шапке главной страницы доступен стримеру, но право управления рынком по-прежнему можно получить через отдельный пароль Render. Статус игры передаётся через активную страницу стримера; она должна оставаться открытой во время рынка. Текущее состояние хранится в памяти процесса Node.js.

## Streamer.bot

Если WebSocket защищён паролем, приложение попросит ввести пароль. Адрес и порт WebSocket меняются в настройках шапки. Тестовый участник и клавиша Space доступны для предпросмотра.

## Аватары

В папке `assets/chibis/reference` лежат 50 спрайтов из предоставленного изображения: увеличенные до 256×256 с прозрачным фоном. Каждый участник получает отдельный вариант.
